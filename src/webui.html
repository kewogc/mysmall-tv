Saved networks

2.4 GHz only. Up to 4 networks; at boot the device joins the strongest one it can see. Tap a scan result to fill a row. Leave a password blank to keep the stored one.

Device name

Reachable as http://<hostname>.local via mDNS. Running several SmallTVs? Give each its own name (smalltv-desk, smalltv-shelf) so browsers and the clawdmeter daemon's --push-to reach the right device. Saving a new name reboots the device.

WireGuard VPN

-
Reaches the device from outside your LAN without forwarding port 80 to the internet. Generate the key pair on your computer (wg genkey | tee dev.key | wg pubkey), put the private key here and the public one on the server as this device's peer; most VPN servers and providers hand you both. Allowed IPs decides what the device routes into the tunnel, and it also sets the tunnel netmask, so a lone /32 address reaches nothing: list the subnet the peer is on (10.6.0.0/24). 0.0.0.0/0 sends everything through the VPN. The private key stays on the device and in its settings export; the page never reads it back. The tunnel needs the clock, so NTP starts whenever it is enabled.

Setup hotspot (AP)

The AP appears when no WiFi is configured or the connection fails. Like the WiFi passwords above, leaving the field blank keeps the stored one; tick the box to clear it and leave the hotspot open.

Screen

Colour

The panels shipped in these devices are not the same part, so the same firmware can look warm on one unit and green on another. Turn a channel down to pull that cast out. If red and blue come out swapped, switch the colour order; if the whole screen looks like a negative, tick Invert. Saving applies it immediately, so you can watch the screen while you adjust.

Button

The capacitive button reads pressed when its touch value drops below this percent of the idle baseline. Lower = firmer touch needed; higher = more sensitive. Next page freezes the carousel on the current page; Home resumes it.

Clock: -
Used by the sunrise and sunset schedule below, and by the radar unless it has its own. The search runs in your browser (open-meteo.com); the device never sends the name anywhere. Leave 0/0 for none.

While the window is active it overrides the brightness and auto-brightness above, except when the sun schedule below is on: then its "When night mode is also on" choice decides. Times are local to the selected timezone; DST is handled automatically. After a reboot the schedule resumes once the clock re-syncs, so the screen may show normal brightness for a few seconds.
The screen rises from the lowest to the normal brightness (the slider above) over the sunrise fade, and falls back over the sunset fade. Sunrise and sunset are worked out on the device. Replaces auto-brightness.

Quick Presets (빠른 지역 선택)

Update from GitHub

Installed: -
Pulls the newest release straight from the GitHub repo. If it fails, use the manual upload below.

Manual update (OTA)

Upload a firmware.bin from the releases page or a local build. The device reboots when done.

Settings backup

The export is the device's config.json, including WiFi passwords and the WireGuard private key in clear text; treat the file accordingly. Import applies everything and reboots.

Password

Off by default, which leaves the page open to anyone on your network. A saved password locks it: the settings page, the API, and the firmware upload then sit behind HTTP digest auth, so the password itself is never sent over the wire. Type the new password twice; if the two fields differ, nothing is saved. Leave both blank to keep the stored password. "Remove password" opens the page again. The clawdmeter daemon's push endpoint stays open, because it has no way to send a password and it only writes the numbers on the screen. There is no password recovery. Forget it and the only way back in is to reflash the device over USB or the UART header, so write it down before you save.
