# mysmall-tv

Прошивка для настольных часов **GeekMagic SmallTV Pro** (ESP32, 8 МБ флеш, экран 240×240 ST7789).

Что умеет:

- часы, погода, графики акций, темы-циферблаты (`.stheme`);
- полноэкранные анимированные уведомления по HTTP (`/api/notify`);
- веб-интерфейс настройки на русском и английском, обновление прошивки по Wi-Fi, самообновление из релизов этого репозитория;
- русский текст на экране и в уведомлениях;
- клиент WireGuard и MQTT.

## Сборка

Нужен только Docker. PlatformIO живёт в образе, тулчейны кэшируются в `~/.cache/pio-docker`.

```bash
./build.sh
```

Результат:

- `dist/smalltv_esp32_8mb/firmware.bin` — образ для обновления по Wi-Fi;
- `dist/smalltv_esp32_8mb/firmware.factory.bin` — полный образ для прошивки через UART с адреса `0x0`.

Первая сборка скачивает около 3 ГБ и идёт несколько минут, следующие — меньше минуты.

Веб-интерфейс лежит в `src/webui.html`. В прошивку он попадает сжатым (`src/webui.h`), `build.sh` пересобирает этот файл сам.

## Установка

```bash
./install.sh 192.168.1.50                # собрать и залить
./install.sh 192.168.1.50 firmware.bin   # залить готовый образ
```

Скрипт заливает образ через `/update`, работает и поверх заводской прошивки GeekMagic, и поверх этой.

- **Поверх заводской.** Настройки Wi-Fi не переносятся: часы поднимут открытую точку `SmallTV-Setup`, сеть задаётся на `http://192.168.4.1/`.
- **Поверх этой прошивки.** Все настройки, включая Wi-Fi, сохраняются: они лежат в `/config.json` на отдельном разделе, который обновление не трогает.

У SmallTV Pro нет USB-UART: порт Type-C только питает часы. Если образ не загрузится, восстановить можно только адаптером UART 3,3 В на внутренней колодке.

## Обновление из веб-интерфейса

Вкладка **System**:

- **Check for latest → Update now** — часы сами скачивают последний релиз с GitHub;
- **Manual update** — загрузка `firmware.bin` с компьютера.

Самообновление ходит на GitHub без авторизации, поэтому репозиторий должен быть публичным.

## Релиз

```bash
./release.sh 1.1.0
```

Скрипт записывает версию в `src/config.h`, собирает прошивку, коммитит, ставит тег `v1.1.0` и пушит. По тегу GitHub Actions (`.github/workflows/release.yml`) собирает прошивку тем же `build.sh` и прикладывает к релизу `mysmall-tv-firmware.bin`. Часы предлагают обновление, только если версия релиза больше установленной.

## Уведомления

```bash
curl -H 'Content-Type: application/json' \
  -d '{"anim":"mailbox","title":"GITHUB","label":"PR merged","ttl":5}' \
  http://192.168.1.50/api/notify
```

| Поле | Обязательное | Значение |
| :--- | :--- | :--- |
| `anim` | да | `phone`, `mailbox`, `sms`, `telegram`, `beer`, `busy`, `cry`, `chicken`, `yahoo` |
| `title` | нет | заголовок сверху |
| `label` | нет | текст снизу, длинный прокручивается |
| `ttl` | нет | сколько секунд показывать, по умолчанию 5 |

`title` и `label` принимают латиницу и русские буквы (UTF-8). Символы, которых нет в шрифте часов, например эмодзи, пропускаются.

## Язык

В веб-интерфейсе, **Clock & night mode → Language**: English или Русский. Настройка переключает язык самой страницы, системных надписей на экране (подключение к Wi-Fi, погода, тикеры) и названий месяцев и дней недели в темах.

Русские буквы есть во встроенном шрифте часов 5×7. Они нарисованы в `tools/make_cyr_font.py`; после правки запустите его, чтобы пересоздать `src/features/theme/FontCyr866.h`.

Переводы страницы настроек лежат в словаре `RU` в конце `src/webui.html`: английский текст остаётся в разметке, в словарь добавляется пара «английский — русский».

## Что где лежит

| Путь | Содержимое |
| :--- | :--- |
| `src/` | прошивка; функции — в `src/features/` |
| `src/config.h` | версия, адрес репозитория для обновлений, значения по умолчанию |
| `platformio.ini` | параметры сборки и отключённые функции (`WITH_HA`, `WITH_USAGE`, `WITH_RADAR`) |
| `partitions/` | таблица разделов, совпадает с заводской |
| `docs/themes.md` | формат тем-циферблатов |
| `tools/`, `examples/themes/`, `skills/` | инструменты и примеры для тем |
| `tests/` | тесты общего кода, запускаются на компьютере |
